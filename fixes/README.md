# 小红书暂停修补（2026-10-11）

这份修补以用户上传的「内容工作台-源码-给GPT.zip」为基础，保留本地修改过的选题卡片、周进度、素材管理、模型切换、页面样式和两条一批的采集逻辑。只修改暂停访问相关的 8 个文件；无需重新安装依赖或下载整套安装包。

## 已确认的问题与修补

- 发布复盘在过滤暂停平台之前返回，小红书已暂停的发布记录仍会触发浏览器访问。现在所有任务先过滤平台，再分配复盘名额。
- 采集器与浏览器网关没有独立的暂停保护。现在 Playwright 和 OpenCLI 都会拒绝暂停来源；浏览器只允许本批已开启的平台，且在读取当前页面 DOM 之前检查范围。缺少浏览器范围配置时拒绝执行工具。
- 运行中保存暂停设置只影响下一轮。现在新增暂停会停止当前任务、关闭自动运行，并保留已保存资料。
- 新建或旧配置缺少暂停字段时，现在默认暂停小红书。已有明确的暂停列表保留，其他设置和数据不重置。
- 报告明确说明暂停平台未采样，其稿件仅为格式适配。手动输入的发布指标仍可用于离线复盘。

这些修补不会撤销平台警告，也不代表任何平台批准了自动采集。当前小红书应保持暂停，通过本人手动提供的素材、指标或有明确授权的数据来源进行研究和复盘。

# 自动研究流程，0.3.0

用户的目标是主动发现平台上的话题和账号线索，给出适合 AI 实践、日常生活和个人心得的判断。指定博主不是采集范围的边界。当前网页聊天没有到 Mac 的远程连接；操作和定时任务由 Mac 后台执行。

先用独立公开适配器限量读取六个来源，每源保留出处、列表性质、时间和实际提供的指标；各源失败独立记录。复用 NewsNow 的端点／解析思路并保留 MIT 许可。抖音公开接口只使用一次性匿名 Cookie，不读取 Chrome 登录 Cookie，临时目录结束即删除。

将外部资料交给无工具的研究规划器，提出三个相关搜索方向与出处；无相关热点时允许明确标为探索。默认浏览器来源十二个，其中八个位置优先给两平台发现入口和三方向搜索，余位刷新到期本人作品或轮换补充对标。旧配置仅补新增开关并升级原默认来源上限，保留其他设置。

浏览器采集使用固定 MCP 网关：导航白名单、最多五秒等待、仅核对当前公开页、固定 DOM 读取。上游关闭隐式快照，强制 raw JSON 不包含其他标签页标题／网址。不暴露模型自定义 evaluate、快照、任意文件写入工具。公开页面媒体静音；不是账号写入操作。每批三个来源，四分钟上限，批间保存已验证作品；参数化小红书详情链接保留原值，身份按作品 ID 去重。

选题分析仅使用已保存证据 ID，不能引用虚构出处。报告列筛选理由、个人可实践角度、证据级别和缺口。榜单位置不能当作跨平台数值比较；推荐和搜索前排不是全站热度；作者主页必须匹配 profile 路由；作者粉丝总数不能写成作品新增关注。账号近期活动只呈现已采集、日期明确的样本数，未知日期单列，完整发布频率／增粉不可得则不下结论。

四个选题及双平台稿件使用上述判断、真实个人素材与发布复盘。停止任务会取消子进程、阻止后续规划／分析／写稿、保留已取得资料并暂停自动运行。前端同步关掉自动运行勾选，避免下次保存误启。

验收分层：单元和流程测试；真实固定 MCP 初始化／工具枚举；真实 Chromium 本地夹具验证链接、标签、媒体、隔离；公共接口实测；使用者 Mac 的平台和模型端到端验收。前三层不替代后两层。此云环境已实测 GitHub 趋势九条，其余公开接口的网络白名单草稿已保存但尚未生效，因此未称流程已跑通。

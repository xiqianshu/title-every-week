# Mac 个人内容自动化程序

用户已明确授权助手自行决定实现方法、编写脚本并复用已有 GitHub 代码。按这一授权直接实现并测试，不再要求用户逐阶段选择技术路线。当前云端会话没有访问用户 Mac 的能力；交付安装包后，本机两平台实测仍是必要验收。

## 目标与默认运行方式

Mac 开机、未休眠且联网时自动采集，复用本机已登录的 Chrome。每天北京时间 09:00 收集研究材料与本人已发布内容的数据；每周一生成四个核心选题和两平台各四份稿件。休眠后恢复时补做当天一次任务，不重放所有历史任务。首次没有选题包时生成一次。中文操作页可随时触发采集、选题或复盘，无需终端输入提示词。

第一版不为当前网页聊天提供远程 Mac 控制接口；用户要的主动运行由 Mac 上的定时任务实现。内容包含 AI 实践、生活和心得，真实素材不足的篇目必须显示待补材料，不能编造职业案例、生活或收益。

## 结构与数据

- Node >= 22，核心服务使用标准库；固定依赖 Codex 0.161.0、Playwright MCP 0.0.83、OpenCLI 1.8.8。
- 默认 Playwright 采集：Codex 非交互执行，限定读取／导航工具，结构化输出，扩展连接令牌仅保存在本机权限 0600 的私有文件中；令牌未配置时直接提示，不进入反复连接确认。
- 可选 OpenCLI 采集：调用固定读取命令，不接受任意 shell 命令。采集适配处理缺失指标与真实零值，丢弃由笔记 ID 推算的发布时间。
- 浏览器连接、凭据与资料留在 Mac；模型生成会通过用户已经使用的 Codex 服务处理资料。后台不会自动替用户发布内容。
- 来源请求只能是两平台公开 URL 或有界关键词；采集结果必须对应实际请求、保留来源 URL 与采集时间。未知指标为 null。
- 本地 JSON 文件存配置、素材、已发布记录、来源快照和任务历史；原子写入，跨进程任务锁，同一内容去重但保留历次指标快照。
- 生成输入含已确认个人资料、素材、来源和历史复盘；模型结构化输出须引用有效来源 ID、四个核心题、两平台稿件及待补事实。拒绝无来源的采集输出或模型杜撰的来源编号。
- 复盘跟踪发布后 72 小时与 7 天窗口。实际采集晚于窗口时明确标为延迟观测；公开数据缺失不作流量／转化推断。

## 操作与安装

中文本地页提供运行状态、报告、账号／关键词清单、个人素材及发布记录。服务只监听 127.0.0.1，写操作验证 Host、Origin 与自定义请求头；报告路径禁止越界，页面按文本呈现外部内容。

安装脚本保留现有 ~/creator-workflow，把程序放入其 automation 子目录，安装固定依赖并注册本用户的 launchd 服务。程序后台保活，终端关闭后仍运行；Mac 关机或休眠时不保证准点执行。提供打开工作台和停用后台入口。

## 失败与验收

每项采集有超时，平台登录／验证码阻止后停止该平台后续尝试。无有效数据时保存失败原因，不生成伪造选题包；部分平台成功时报告必须标明缺失平台。任务失败释放锁并保留上次成功报告，不静默覆盖。

开发验收包括来源校验、指标空值、去重、复盘时间窗、模型输出契约、任务互斥、部分失败、子进程超时、HTTP 操作和安装调度配置。云端测试不替代 Mac 上真实抖音／小红书访问、Chrome 连接和通知的验收。
